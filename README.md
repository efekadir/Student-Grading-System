# Student-Grading-System
A Java console application that automates the grading process for multiple students across multiple tests. It utilizes a 3-dimensional array (`char[][][]`) to store student answers and dynamically compares them against a 2D answer key. The system features automated array sizing and dynamic nested loops to calculate and print a formatted grade report for each student.
